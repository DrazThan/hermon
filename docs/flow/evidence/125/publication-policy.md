# Public validation evidence

Publish source, synthetic fixtures, behavioral assertions, test outcomes and
bounded capability summaries. Keep live workflow records and operator setup
outside the public repository.

Do not publish credentials, authentication state, private issue or knowledge-base
content, live session identifiers, usage telemetry, owner identities or local
machine paths. Example configuration uses placeholders and must be completed
locally before use. Raw live probes and receipts are retained privately.

Public validation logs normalize operator paths. Active export manifests hash
those redacted bytes; historical manifests retain their original hashes. Test
source, fake executables and acceptance assertions are unchanged. Byte-exact
originals remain in the private evidence archive.

The prepared publication history retains the independent RED test commits before
implementation and the documented fixture corrections. Credential-pattern scans
and in-memory exact-value checks found no matching credential values. Private
operational metadata was withheld from the public candidate. This is a scoped
review of the proposed change, not a guarantee about unrelated repository history.
